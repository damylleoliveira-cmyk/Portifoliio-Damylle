# Projeto: Tabela Checklist em Python

Essa tabela foi desenvolvida com o objetivo de organizar e apresentar informações de forma clara e objetiva.  
Como temos várias obrigações diárias, esse aplicativo permite ao usuário marcar e desmarcar tarefas conforme suas necessidades.  

Foi desenvolvido em Python de forma prática para ajudar na organização do dia a dia.
